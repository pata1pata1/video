# 横長トーク動画の編集パターン（案）

2026-11-03。reference 学習（S2）の4本 `ref-landscape-001`〜`004` から、ユーザーが自分で編集した完成動画の傾向をまとめたもの。

**2026-11-04：6章の5項目を、ユーザーの指示でカット候補の既定値にした**（横長トーク動画だけ。使い方と条件は `docs/design.md` の6.1）。

元データ：`style-data/observations/ref-landscape-00{1..4}.json`（数値はすべてここから集計）。`talking-test-01` はこのツールの候補をユーザーが承認したもので、ツールの既定値の影響を受けているため、傾向の根拠には使わず比べるだけにする。

- 並べ替えはほとんどしない。元動画の順番どおりに残すのが基本

## 2. 間（ま）

### 文の区切り（文が終わってから次の文まで）

| 元の間 | 完成動画に残した間（中央値、4本の範囲） | 扱い |
|---|---|---|
| 0.7秒未満 | 0.38〜0.58秒 | **ほぼそのまま残す** |
| 0.7〜1.5秒 | 0.35〜0.81秒（003 は 0.76〜1.22秒） | 案件によって残したり縮めたり |
| 1.5秒以上 | 0.42〜0.72秒（003 は 0.95秒） | **約0.5秒まで縮める**（間の途中をつなぐ） |

→ 文の区切りは **約0.5秒（0.4〜0.7秒）** に整える。今のツール（両側に0.2秒残す → 約0.4秒）より少し長い。

### 句の途中（文の途中で止まった間）

- 長さに関係なく**必ず縮める**（4本すべて joined）
- 残した間の中央値は 0.25〜0.63秒、全体ではおよそ **0.3〜0.5秒**。文の区切りより短い

### 間だけの削除

- 0.1〜0.2秒の短い間も削っている（間だけの削除の下位10%が 0.16〜0.2秒）。今のツールは 0.7秒未満の間を候補にしないので、ここはツールより細かい

## 3. 始まりと終わり

- **始まり**：最初の言葉の前は 0〜0.3秒だけ残す
- **冒頭の撮り直しは、最後の1回だけ残す**（001：「はい、今日はですね」を何度も言い直した59秒を削除。002：18秒、004：10秒）
- **終わり**：最後の言葉の後は 0.1〜0.4秒。締めのあいさつ（「じゃあバイバイ」など）は**残す**（縦型ショートとは違う）

## 4. フィラー

（Whisper が文字にしたものだけ。文字にならなかった声は数に入らないので、実際はもっと削っている）

| 言葉 | 文頭 | 文の途中 | 扱いの案 |
|---|---|---|---|
| えー・えーと・えっと・うーん・あのー | 11/13 カット | 句の頭 3/3 | **ほぼ削る** |
| あの | 5/7 | 2/4 | 文頭は削る、途中は確認 |
| まあ | 12/16（ほぼ 002 だけ） | 1/1 | 文頭は削る案（確認あり） |
| その | 0/1 | 3/3 | 言いかけの「その」は削る |
| なんか | 6/20（30%） | 0/3 | **基本は残す**（話し方の一部） |

## 5. 声を含む削除（何を削っているか）

文字を確認すると、だいたい次の5種類：

1. **言い直し・撮り直し**：同じ言い出しを繰り返した前の方（冒頭が特に多い）
2. **同じ言葉の重ね**：「でで」「だからだから」「このこのこの」
3. **言いかけて止めた文**：最後まで言わずに別の言い方にしたもの
4. **脱線・トラブル**：撮影中の機器の不調についての独り言（004、54秒）など、その場の独り言
5. **重なる内容の話**：同じことを2回話した時の片方、まとめに入らない話（004 の 176秒：後で話し直した予定の話と、後半の話し始め）

声を含む削除の長さの中央値は 2.1〜3.3秒。1〜3文字だけの削除（言いかけ・重ね）も多い（各案件の3〜6割）。

## 6. 既定値への反映（2026-11-04 採用）

| 項目 | 前のツール | 今の既定値 |
|---|---|---|
| 文の区切りの間 | 両側に0.2秒（約0.4秒） | 約0.5秒 |
| 句の途中の間 | 文の区切りと同じ | 約0.3秒（文の区切りより短く） |
| 間だけのカット候補の最小 | 0.7秒 | 文の区切りは0.7秒のまま、句の途中は0.5秒から |
| 冒頭の撮り直し | 隣の文が似ている時だけ | 最後のテイクを残す案（前のテイクが長い時は確認だけ） |
| 終わり | 最後の言葉の後 0.3秒 | そのまま（0.1〜0.4秒の範囲） |
| 強いフィラー（えー・えーと・えっと・うーん・あのー） | 削る案（確からしさ 0.6） | 原則削る案（確からしさ 0.8） |
| なんか | 確認だけの候補 | 候補にしない（残す） |
| 言葉の重ね（でで・このこの） | 「、」を挟んだ2文字以上だけ | 文をまたいでも見つけて、最後の1回を残す |
| 脱線・トラブル・重なる話 | Claude の提案 | そのまま（自動では削らない。必ず確認） |

## 7. 新しい動画での検証

学習に使っていない動画での再現度は `npm run evaluate` で測る（`docs/design.md` の15章「検証」）。基準値（学習に使った4本、＋追加候補）：適合率 平均 82.4%・再現率 40.4%（確認だけの候補も含めると 57.6%）・時間の一致 68.1%。新しい動画の結果は `npm run evaluate -- summary` で、この基準値と並べて見る。
