## カット編集（元動画との比較）
| 削った物 | 例 |
|---|---|
| 言い直し・撮り直し | 冒頭の「はい名古屋デモに〜」は3回撮っている → **最後のテイクだけ採用**。途中の「なんかここ最近あれですよね／ワンワンの名古屋デモの参加者が…」の試行も丸ごとカット |
| 文頭のつなぎ言葉 | 「はい」「でね」「なんか」「皆さんも」「だからもう」「別にその」 |
| 文中の余計な一語 | 「メインは**僕**ワンワン」→「メインはワンワン」、「ごくごく一部の**5%とか**」→ 削除、「**初めて**今までそういう〜」→ 削除 |
| 繰り返し | 「なのにも変わらず」の2回目、「もう会うこともない人なわけですよ」（直前と同じ意味） |
| 脱線した話 | 「同じ場所でまた別のイベントをする形でもいい」のくだり（約10秒）を丸ごとカット |
| 締めの挨拶 | 「ありがとうございました／ご視聴ありがとうございました」はカット。**本題の最後の一言で終わる**（→ ショート動画では締めの挨拶なしが方針） |
| 間 | フレーズ間の無音はほぼゼロまで詰める（0.3秒以上の無音なし） |

- 言い直しで2回言ったものは、**言い切れている方**を採用（「対象の方ご連絡いただければ嬉しいなと思います」は2回目）
- 締めは2パターン撮っていて、後の方（「そういった方たちの話も聞いてみたいんで → ご連絡いただければ嬉しい」）を採用
- カット数：約40〜50か所（2〜3秒に1回）。ジャンプカットをそのまま見せている（ズームやトランジションでごまかしていない）
- 照明の変化（途中で赤っぽくなる）は元動画のまま。色補正なし

## 構成（話の流れ）
1. **呼びかけ（フック）**：「名古屋デモに参加しようと思ったけど／やっぱり辞めてしまったあなたへ」… 対象者を名指しで呼ぶ
2. **現状**：離脱者が増えている → 自分は悲しい
3. **初心を思い出させる**：SNSで知って、初めて参加しようと思った気持ちを忘れないで
4. **主張**：運営の問題はおまけ。メインは旺旺
5. **たとえ話**：修学旅行のバスガイド・運転手 → メインは修学旅行
6. **提案**：イベント中だけ指示に従えばいい、その後は自由行動
7. **締め（行動の呼びかけ）**：それでも嫌な人の話を聞きたい → ご連絡ください

## テロップ
- **話した言葉をそのまま字幕にする**（要約しない）。ただしカットした言葉は字幕にもない
- 1枚＝短いフレーズ（1行あたり約6〜9字）、**最大2行**。意味の切れ目で改行
- 位置：上段映像の下寄り（画面高さ約44%）、中央揃え、全編固定
- 書体：太い丸ゴシック、白文字＋黒の縁取り
- 出し方：**小さく出て拡大しながら出現**（数フレーム）。ai-voice 001 と同じ系統のエフェクト
- 表記：固有名詞は正しく直す（音声「ワンワン」→ 字幕「旺旺」）、「事」など漢字表記もあり
- 切り替えは話のフレーズに同期し、カット点とも大体そろう

## 音声
- 話者の地声のみ。BGM・効果音なし（フレーズの間も部屋の環境音レベル）
  - → BGM はアップロード時にプラットフォーム側の曲を付ける（ai-voice と同じ）
- 元動画より音量を約4dB上げている（平均 -32.3 → -28.5dB）
