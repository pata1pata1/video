## 構成（台本の流れ）
A001 の「プロフィール紹介」とは違い、**話題・ニュース型**（1つのエピソードだけを紹介する）
1. フック：「ホストコールの東條カヲルさんが、努力家すぎると話題になっています。」… 所属＋名前＋「〜すぎると話題」
2. エピソード：「なんと、自分のSNSのフォロワー全員に自らDMを送る。」
3. 意味づけ：「こういった簡単だけど面倒な事をどれだけこなせるか。」
4. 締め：「〜なカヲルさんに、さすが売上1,000万超の元ボーイズバー店員と称賛の声が上がっています。」… 世間の反応で終わる

- **静止画スライド**（A001 は映像クリップのみ）。ズーム・パンなどの動きはなし、切り替えはカット
- **カットは文の切れ目に揃えている**（5.1秒＝1文目の終わり、14.0秒＝3文目の終わり）。しかも**話の中身と画像を対応させている**（所属紹介→番組画面、DMの話→DM画面、称賛の声→街頭インタビュー）
  - A001 は「素材が尽きたら切り替え」で音声と揃えていなかった。画像素材の場合は話題に合わせる、と考えられる
- 画像は全部「横幅いっぱい」で、縦の余りは黒。縦を埋めるための拡大トリミングはしていない
- タイトル文字は最初のカットだけ（黒帯の余白がある画面のみ）
- 画像2に元から焼き込まれた字幕「好きな女性のタイプは？」がテロップの後ろに透けて見え、テロップと重なる瞬間がある（後述の確認事項）

## テロップ
- 12枚。台本は文単位でベタ書き（空行区切りではない）だが、テロップは短いフレーズに分かれている
  | # | テロップ |
  |---|---|
  | 1 | ホストコールの／東條カヲルさんが |
  | 2 | 努力家すぎると／話題になっています |
  | 3 | なんと／自分のSNSの |
  | 4 | フォロワー全員に／自らDMを送る |
  | 5 | こういった |
  | 6 | 簡単だけど／面倒な事を |
  | 7 | どれだけこなせるか？ |
  | 8 | そういった／部分の努力を |
  | 9 | 惜しまない／カヲルさんに |
  | 10 | さすが売上／1,000万超えの |
  | 11 | 元ボーイズバー／店員と |
  | 12 | 称賛の声が／上がっています |
- 台本との差：「こなせるか。」→「こなせるか？」、「1,000万超の」→「1,000万超えの」（テロップ側で修正）
- 1行あたり約5〜9字、最大2行（A001 と同じ）
- 位置：**画面中央よりやや上（高さ約45%）**、全編固定・中央揃え（A001 は約60%）
- 書体：太めのゴシック、白文字＋**濃いピンク（クリムゾン）の縁取り**。白背景の DM 画面ではピンク文字に見える
- 出し方：小→拡大しながら出現（A001 と同じ Vrew の文字エフェクト）

## 確認したいこと
- ~~台本は文単位のベタ書き → テロップの区切りは？~~ → 台本.txt は **Vrew に入れる前の普通の文章**。テロップの区切りは Vrew に入れてから作っている
- ~~「どれだけこなせるか？」「1,000万超えの」は？~~ → **テロップ側で修正**（読ませる文と見せる文字を分けている）
- ~~「東條」は誤記？~~ → **誤記**（正しくは冬條）。名前は素材画像の表記と照合すること
- ~~画像2の元字幕は？~~ → **ミス**。今後は消す
- ~~タイトル「鬼努力ホスト」は？~~ → **今回のみ**（型にしない）
- ~~テロップ位置は？~~ → **動画ごとに見やすい位置に変える**
