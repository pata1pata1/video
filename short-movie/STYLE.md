## ニュースショート動画（上部字幕固定型）

ニュース系ショート（事件・炎上・時事ニュース・話題解説）の**標準の型**。ニュース系はまずこの型を使い、特別な理由がない限り下部字幕ではなく上部字幕固定にする（ユーザー指定） [N001]
- 形式：ai-voice（AI音声ナレーション＋画像）。話者が映る talk のニュース型（T002・T003）は、これまでどおり talk の上下2分割を使う
- 制作：`templates/news-short-top/`（アプリ。コピーしない）を `scripts/sm.mjs` で使い、動画ごとのデータは `short-movie/<id>/` に置く（2026-11-03〜、共通remotion）。手順はテンプレートの README
- 共通ルール（声のみ・締めの挨拶なし・テロップの書体と出し方）はそのまま

### 画面構成（1080x1920・9:16）
```
┌──────────────┐ 0
│   字幕専用帯     │ 60〜300px（目安）：字幕だけ。暗め・シンプルな背景
├──────────────┤
│   画像内見出し     │ 中段：見出しは字幕帯の下から始める
│ メインビジュアル・補足 │ 下段
└──────────────┘ 1920
```

### 最重要：視聴者に文章を読ませない（ユーザー指定、2026-11-19） [N003]
動画は文章を読む媒体ではなく、映像と音声で理解する媒体。
- 詳細はナレーションで言う。画面上の文字は最小限（短いキーワード・数字・見出しだけ）
- **1画面1メッセージ**。長文テキストカードは禁止。台本の文章をそのまま画面に出さない
  - 例：ナレーション「警視庁は39歳の男を強盗殺人未遂の疑いで逮捕しました」→ 画面「39歳の男を逮捕」
  - 例：ナレーション「事件が起きたのは11月16日の夜です」→ 画面「11月16日 夜」
  - 例：ナレーション「被害者は24歳の女性で、病院で死亡が確認されました」→ 画面「被害者 24歳女性」
- 画像の中の文字：1要素12字まで・1画面2要素まで・計20字まで（`input/visuals.json` の `onScreenText` に登録し、`production.mjs validate` が止める）。出典・注記は画面に書かず概要欄へ
- 字幕も長文を一度に出さない（1枚16字まで・最大2行）
- 写真・映像・図・地図・数字・アイコン・短い見出しで伝える。**同じ静止画・同じレイアウトを長く出さない**（1画面6秒まで・平均4秒以内に画を変える）
- 冒頭3秒で核心を言い切る（前置き「整理します」から入らない）。冒頭3秒の中で画を変える。尺は30〜55秒（上限65秒）。最後は本題の一番強い一言か問いで終える
- 公開前に `production.mjs quality-check`（QUALITY_GATE）を通す。fail は公開しない
- 映像そのものの強さ（2026-11-20、tank-20261119「前よりかなり良い。映像が弱い。」）：テキストカードだけ・模式図だけで構成しない。可能なら実物・公式素材・場所・物・車両・製品（できればその出来事の映像・動く映像）を見せる。図解でも画面全体を単純なカードにしない。同じデザインの画面を続けない。冒頭1〜3秒に一番強い画。QUALITY_GATE=pass は公開承認ではない（人が見てから）

### 失敗例 N003（nakano-20261119、2026-11-19、公開せず）
自動選定・自動制作の最初のニュースショート。overallQuality 24／100・QUALITY_GATE fail。ユーザー評価「全然ダメで、視聴されないことが分かるレベル」。学習データ：`../../content-ops/learning/prepublish/nakano-20261119.json`
- 冒頭が「東京・中野区の路上で…」と場所から入り、5〜9秒で「報道で分かっていることと…整理します」の前置き。最初の画面が12秒変わらない
- 77秒で画像7枚（平均11秒・最長22秒の静止画）。全画面が紺のテキストカードで同じレイアウト。写真・映像・地図なし
- 画面の文字が1枚36〜95字。字幕と画像内の大きな文字を同時に読ませ、ナレーションの文を画面にも重複
- 抽象的な夜景（ランダムな窓）とぼかした赤青の丸は、作り物感が強く何も伝えない
- 「〜によると」「〜ということです」が1分に6回、低い一定の声で単調。最後は「報道の出典は概要欄に」で終わる
- テンプレート（news-short-top）の問題ではない（N001・N002 は写真・映像で成立）。安全方針で人物・現場を外した結果、**見せる素材がない題材を選んでいた**ことと、台本・画面の作り方の問題

### 字幕
- 位置は**画面上部に固定**：中心 X=540・Y=175。**全カット共通・画像ごとに変えない・自動で上下に動かさない**。字幕帯の外には出さない [N001]
- 最大2行・中央揃え。長い1行は文字を小さくして帯に収める（最大72px） [N001]
- 「、」「。」は表示しない（「？」「！」は残す）。読ませる文とテロップの文字は別に直してよい（ai-voice と同じ） [N001]
- 書体・縁取り・出し方は共通のテロップと同じ（太いゴシック、白文字＋濃い色の縁取り、小→拡大で出現） [N001]
- 1枚＝音声1フレーズ。開始時刻は VOICEVOX のモーラ長から計算し、faster-whisper で声とのズレを確認する（N001：最大0.12秒） [N001]

### 画像
- **画像は最初から「上部字幕帯あり」で作る**。字幕帯（上から60〜300px）に見出し・重要情報・顔・主役要素を置かない [N001]
- 全画像で字幕帯の高さ・位置・余白をそろえる（N001：字幕枠 x44〜1036・y45〜295、画像パネル x107〜973・y330〜1875） [N001]
- 字幕帯の下に「画像内見出し → メインビジュアル・補足」の順に置く [N001]
- 下端付近と右端には YouTube ショートの UI（タイトル・チャンネル名・ボタン）が重なるので、重要情報を置かない（範囲は目安。投稿後に実機で確認する） [N001]
- 秒数や編集用の文字は入れない [N001]

### 動き・切り替え
- 字幕帯と画像パネルの外枠は動かさず、**パネルの内側だけ**をゆっくりズーム（1.00〜1.04倍）・小さくパンする。画像内の文字が切れない範囲に収める [N001]
  - ※ai-voice の「静止画は動きなし・切り替えはカット」[A002] とは別。ニュースショートはこちらを使う
- 画像の切り替えはクロスフェード（約0.33秒）。話している中身に合う画像を、文の切れ目で出す [N001]

### 映像パネル型（素材が動画のとき）
- 素材が動画（現場の撮影・画面録画など）のときは、画像の代わりに**パネルの中で素材動画を流す**。字幕帯・パネルの位置は画像のときと同じ（字幕枠 x44〜1036・y45〜295、パネル x107〜973・y330〜1875）で、枠はテンプレートが描く（`script.json` の `clips`） [N002]
- 素材はパネルの高さに合わせて拡大し、左右を切る（黒帯なし）。素材に音楽が入っているときは元の音を使わない（ユーザー指定） [N002]
- 台本の順に場面を並べ替えてよい。素材より台本が長いときは、スロー（0.4倍程度まで）と同じ区間の使い回しで合わせる（ユーザー了承済み）。ピンぼけ・カメラ移動中の区間は避ける [N002]
- 数字（視聴者数など）を言う場面は、止め画にしてその数字へズームする [N002]
- パネル下端に小さな説明文（例：「AIライブ配信の現場」）。映像で確認できないこと（「無人」など）は書かない [N002]

### フリー映像の札（2026-11-22〜）
- 画像だけだと静止画とズームの連続になるので、街並み・夜景・物・作業の様子など**話の場面に合う一般的な実写映像**を Pexels から取って札に挟んでよい（`sm.mjs footage`。作り方は `templates/news-short-top/README.md`）。字幕帯・パネルの位置は画像・映像パネル型と同じ
- 取った映像は必ず目で見て、話の中身と合うか・人物の顔や事件現場と特定できるものが映っていないかを確かめる。合わなければ使わない（イメージ映像を事実の映像のように見せない）

### 声・音
- 声は案件ごとに指定（N001：VOICEVOX 青山龍星 ノーマル ID13・速度1.12、N002：雨晴はう ノーマル ID10・速度1.1）。文と文の間は約0.4秒 [N001]
- BGM・効果音なし（共通ルール）。音量は -14 LUFS 前後 [N001]

### 確認（書き出し後）
- 全場面のコマを抜き出し、字幕位置・字幕帯からのはみ出し・画像内の文字切れ・見出しとの重なりを見る
- 字幕と声のズレ・尺・音量を測る

## 語りのショート（story-short、つぐみの開運チャンネル型）

**制作のたびに `../../content-ops/workspaces/tsugumi-kaiun/creative-rules.md`（題材・タイトル・台本・映像・ナレーションと BGM のルール。参考チャンネルの分析から）を先に読む。** 下の世界観（色・声・BGM）はそのまま、構成と演出はそちらを優先する（天岩戸・天赦日は「非常につまらない」：説明を順に話すだけで自分ごとの仕掛けがなかった）

開運・神話・占い・暮らしの題材を、画像＋落ち着いた女性の語り＋控えめな BGM で伝える縦型 Shorts（2026-11-22、セット02 tsugumi-kaiun）。テンプレートは `templates/news-short-top` をそのまま使い、台本（script.json）の値で世界観を変える（新しいエンジンは作らない）。content-ops の制作依頼の種類は `story-short`。最初の動画：tsugumi-amano-iwato-20261122（天岩戸の神話、55秒、QUALITY_GATE pass 87）

- 対象：40代以上の女性。冒頭3秒で引く一言（例「ある日、世界から太陽が消えました」）、最後は問いかけ・やさしい一言（例「あなたの心の岩戸は、開いていますか？」）
- 声：VOICEVOX No.7（読み聞かせ、speaker 31）・speedScale 1.38 前後（1.2 では遅く長くなった）。尺 35〜60 秒
- 色：藤色・金・生成り。字幕の色は `"captionColor": "#6b3fa0"`。事件向けの強い赤字・不穏な演出・効果音は使わない
- 画像：上部の字幕帯（60〜300px）は濃い藤色。**全面の画（layout full-bleed）と枠つきの画面（panel-text）を交互**にし、地図・写真など違う種類の画を挟む（同じ枠が10画面続いて visualVariety 28 で fail した。visuals.json に `layout` を書く）。見出しは明朝・生成り／金、1要素12字まで
- 素材：パブリックドメインの浮世絵・古典資料、ライセンスが明確な写真（ウィキメディア・コモンズ。概要欄にクレジット）。現代の写真をイメージとして使うときは「イメージ」と分かるように
- BGM：`node scripts/make-bgm.mjs` で作る自作の音源（`_shared/bgm/calm-pad-01.wav`。外部の曲を使わないので著作権の問題がない。音声ファイルは Git 管理外なので、ない PC では作り直す）。台本に `"bgm": { "file": "_shared/bgm/calm-pad-01.wav", "gainDb": -20 }`。声の下で自動的に下がり（ダッキング）、最後はフェードアウトする（共通 remotion の short-movie encode）。声が聞き取りにくければ gainDb を下げる
- 品質ゲート：評価設定 story-short（quality-v2-story。制作依頼の種類で自動。依頼のない動画は script.json の `"qualityProfile": "story-short"`）。語りの速さ 5.0〜7.5 字/秒・尺 35〜60 秒、「〜とされる」を伝聞として数えない、問いでない冒頭の意外性も引きとして数える、題材の主役の実物（神話の古典の絵・暦の資料・神社など）は visuals.json の `"realness": "subject"`。合格点はニュースと同じ
- 表現：占い・スピリチュアルは娯楽・文化として（「〜とされる」「占いでは」）、健康は公的機関などの根拠の範囲だけ（治る・効く・予防できるを言わない）、神話・伝説は「〜に伝わる」と伝承として語る

## X動画＋ナレーション（@news_mt型）

ユーザーのチャンネル（youtube.com/@news_mt）の過去のショートから学んだ型。Xに投稿された動画をそのまま主役の映像にし、元の音を活かして要所だけナレーションを入れる（2026-11-20、ユーザー提示）。根拠：`[X001]` kEK0NWypGcw（駐車場で音楽を流す迷惑客とパトカー、45秒）、`[X002]` -J6QS8ArLhI（渋谷で恥をかく珍走団、31秒）、`[X003]` 4wif7GagEqc（暴走族を震え上がらせる半グレ、89秒、130万回再生）。テンプレートは `templates/x-clip-narration/`、最初の検証サンプルは `rappa-20261120`（2026-11-20 公開・cleanup 済み。記録は content-ops の campaign `xclip-rappa-20261120`）

**上の「ニュースショート動画（上部字幕固定型）」（`news-short-top`）とは別の制作パターン**。画像を並べて報道の事実をナレーションで伝える news-short-top に対し、こちらは他人が撮った動画1本と元の音が主役。2つの型・テンプレートの決まりを混ぜない。content-ops では制作依頼 `x-clip` と、X 動画の候補の経路（`topics clips`・`campaign create-from-clip`、2026-11-20）につながっている。素材の利用確認が記録されるまで取得・制作・公開しない

- ジャンル：迷惑行為・暴走族・半グレ・ヤクザ。ハッシュタグは `#迷惑行為 #暴走族 #半グレ` など [X001][X002][X003]

### 映像
- **X動画1本を主役にする**。最初から最後まで流し、細かく切り刻まない（切り貼りしない） [X001][X002][X003]
- 縦の素材は全画面、そうでない素材は全幅で中央＋背景にぼかした同じ映像（テンプレートの `contain`） [X001][X002][X003]
- 右下に小さく**出典**（「出典：X @アカウント」、テンプレートの `credit`）

### 音・ナレーション
- **元の音を活かす**（エンジン音・ラッパ・警察のアナウンス・怒鳴り声が見どころ）。ナレーションの間だけ元の音を下げる [X001][X002][X003]
- ナレーションは VOICEVOX（雨晴はう・青山龍星）。**冒頭でタイトルを読み上げ**、あとは場面の説明を**数か所だけ**（「そこへ男が注意しに行きました」「しかし失敗」） [X002][X003]
- **見どころの音にはナレーションをかぶせない** [X002][X003]
- **映像で確認できないこと（場所・人物の素性・その後どうなったか）はナレーションで言い切らない**

### 字幕・タイトル
- 太いゴシック、**上部〜中央に大きく**固定
  - タイトル：赤文字＋白縁、**冒頭に大きく**（テンプレートでは最後まで表示したまま） [X001][X003]
  - ナレーション：白文字＋青縁（X003）、または赤文字＋白縁（X002）
  - 現場のセリフ：白文字＋黒縁（「考えろ」「エンジンを直ちに消して下さい」） [X001]
- タイトルの形：「〇〇が〇〇すぎる」「〇〇...〇〇してしまう」。動画の中の一番のオチを言う（強いタイトル） [X001][X002][X003]
- **字幕の大きさは変えない（縮めない）**（2026-11-21、ユーザー指示）：テンプレートは1行が長いと自動で縮むので、ナレーションは1行11字・タイトルは1行9字まで（英数字は0.6字）にし、超えるなら `caption` の `\n` で2〜3行にするか cards を分ける。タイトルを3行にするときは下のナレーション字幕と重ならないか静止画で確かめる
- **タイトルが映像の邪魔になるときは小さくする**（2026-11-21、ユーザー指示）：映像が画面の上まである素材（縦動画の cover など）では `layout.titleMaxFont`（例 72）と `layout.titleY`（例 200）でタイトルを小さく上に寄せる。ナレーション字幕の大きさは変えない

### 素材選び・利用の確認（必須）
- **素材の利用確認が必要なテンプレート**。他人のX動画を「Xに公開されているから自由に転載できる」とは扱わない。制作・公開の前に、1本ごとに人が次を確かめる
  - 利用してよい素材か（公開して利用してよい根拠があるか）
  - 投稿者自身が撮影した動画か
  - 再投稿・転載のアカウントではないか
- チャンネルで既に使った題材と重ねない（`yt-dlp --flat-playlist` で一覧を確認する）
- **投稿者がもうナレーションやテロップを入れた編集済みの動画は使わない**（まとめアカウントの再投稿に多い）
- 候補の探し方の例：Xで `filter:videos min_faves:500` など（自動で取得・ダウンロードする仕組みはない）。content-ops では Claude が報道・公式発表から X の動画を見つけて clip-inbox に評価を書き、X 公式の oEmbed で投稿を確かめる（`../../content-ops/docs/topic-discovery.md`「X 動画の経路」）

### 台本の書き方
- 台本は**普通の文章で書く**（Vrew に入れる前の状態）。テロップ1枚ごとの区切りは Vrew に入れてから作る（ユーザー確認済み） [A002]

- **読み上げた言葉はテロップに全部出す**。A003 で「ぶっ飛んでる男」がテロップから抜けたのはミス（ユーザー確認済み） [A003]
- 台本は一字一句そのまま読ませる（読み替えなし） [A001][A002]

- **人名などの固有名詞は素材画像（番組テロップ・SNS）の表記と照合する**（A002 は「冬條」を「東條」と誤記した） [A002]

### 構成（暫定）
**プロフィール型** [A001]
1. **フック**：名前より先に「すごい肩書き＋見た目の魅力」で引く（例：「ルイ・ヴィトンのアンバサダーを務める／驚くほど美しい男性」）
2. **正体**：所属 → 名前
3. **プロフィール**：出身・生年月日・ビジュアルの特徴
4. **実績**：年号付きで時系列に（「そして2023年には」「2024年には」）
5. **人柄**：ギャップ（ステージ／普段）
6. **締め**：「これからも目が離せません」系

**話題型**（エピソード1つだけ・短め） [A002]
1. **フック**：所属＋名前＋「〜すぎると話題になっています」
2. **エピソード**：「なんと、〜」
3. **意味づけ**：そのエピソードのすごさを一般論で言う
4. **締め**：世間の反応「〜と称賛の声が上がっています」

**事件・ニュース型**（事件映像を見せる） [A003]
1. **フック**：所属＋名前＋何が起きたか（「ブレイキングダウンsakkki選手のバー襲撃映像が公開されました」）
2. **映像の説明**：「そこに映っていたのは、〜」と、映っている中身を言葉で追う
3. **意味づけ**：「〜として有名な〜ですが、こんなことをして大丈夫なのでしょうか」
4. **今後**：「今後〜への影響が出てくると思いますが」
5. **締め**：**視聴者への問いかけ**「あなたは〜してほしい？」（コメントを誘う）

**現場紹介型**（珍しい現場の映像を見せる） [N002]
1. **フック**：**一番の驚きを最初の一言で言い切る**（「この美女、実はこの世に存在しません」）。「〜が話題になっています」から入るのは弱い（ユーザー指摘）。映像も一番目を引くアップから始める
2. **正体**：驚きの答え（「AIが作った配信者なんです」）
3. **引きの映像で全体を見せる**：「カメラを引くと、そこには〜」
4. **仕組み**：映像から推測したことは「〜とみられます」
5. **数字**：映像に映る数字（視聴者数など）
6. **締め**：視聴者への問いかけ（「あなたは〜したいと思いますか？」）

### 映像
- 素材は対象人物の**映像クリップ**か**静止画**（番組画面・SNSのスクショ・他媒体のスクショ）。静止画のときは動き（ズーム・パン）なし [A001][A002]
  - ※ニュースショートはパネル内の軽いズーム・パンとクロスフェードを使う（上記） [N001]
- 素材の元音声は使わない [A001]
  - ただし**事件映像（防犯カメラなど、現場の音に意味がある素材）は元の音を小さく残す**（A003：元の音量から約-6dB、ナレーションの下に流す）（ユーザー確認済み） [A003]
- 映像クリップ：縦長でない素材は拡大して画面いっぱいにする（黒帯なし） [A001]
- 静止画：**横幅いっぱいに置いて、縦の余りは黒**（暫定） [A002]
  - 2枚組の画像は左右に切り分けて別カットにする [A002]
- **事件映像＋本人の写真の上下2分割**（事件映像があるときの型）（ユーザー確認済み） [A003]
  - 0〜約480px：黒帯。テロップはこの帯の下寄りに置く（2行目が映像の上端に少しかかってよい）
  - 約480〜1230px：事件映像。横長素材を高さに合わせ、左右を少し切る
  - 1230〜1920px：本人の写真。横幅いっぱい、上下を切って顔を中心に
  - 全編この形のまま。映像は1本を切らずに流し、写真は動かさない（talk の上下2分割の ai-voice 版：話者の代わりに本人の写真）
  - ※A003 の、声が終わった後の約3秒（声・テロップなしで映像だけ）はその動画だけ。型にしない（ユーザー確認済み） [A003]
- 切り替えはカット（トランジションなし） [A001][A002]
- 静止画のときは**文の切れ目で切り替え、話している中身に合う画像を出す**（所属の話→番組画面、DMの話→DM画面）。映像クリップのとき（A001）は素材の区切りで切り替えていた [A001][A002]
- **クリップの使い回しは避けたい**。素材の合計時間はナレーション尺以上を確保する（A001は不足で2回使用） [A001]
- **素材に元から焼き込まれた字幕・文字は消す**（ぼかし・トリミング等）。テロップと重なって読みにくくなる（A002 は消し忘れ）（ユーザー確認済み） [A002]
  - ※A002 冒頭のタイトル「鬼努力ホスト」はその動画だけ。型にしない [A002]

### カット編集
- 残る長さは結果であって目標値はない（T001：237秒→112秒＝47%、T002：226秒→135秒＝60%、T003：76秒→40秒＝53%、T004：107秒→58秒＝54%）。下のルールで不要な部分を削り切った結果が完成尺 [T001][T002][T003][T004]
- **言い直し・撮り直しは、最後のテイク／言い切れている方を採用**（T003：「騙し取って」→言い直した「騙し取ったという」、T004：「私ですから」→「自分がやりますんで」） [T001][T003][T004]

- 考え込んでいる長い無言は詰める（T002：約17秒の無言） [T002]
