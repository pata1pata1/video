# 作風ガイド

各項目の末尾 `[A001]` `[T001]` は根拠になったサンプル（A＝ai-voice、T＝talk、番号はタイプ内の連番）。1本だけの根拠は「暫定」。複数本で確認できたら確定扱いにする。

## 共通

- 縦型 1080x1920 / 30fps（素材が60fpsでも30fpsで書き出す） [A001][A002][T001][T002][T003]
- 編集ソフトは **Vrew** [A001][A002][T001][T002][T003]
- 書き出しは**声のみ**。BGM はアップロード時にプラットフォーム側の曲を付ける（こちらで BGM・効果音を足さない） [A001][A002][T001][T002][T003]
- **締めの挨拶（「ご視聴ありがとうございました」等）は入れない**。本題の最後の一言で終わる（ショート動画の方針） [A001][A002][T001][T002][T003]
  - ※T002 の最後の黒背景エンドカード（文字だけの一言）はその動画だけ。型にしない [T002]
- テロップ
  - 1枚＝短いフレーズ、**最大2行**、意味の切れ目で改行 [A001][A002][T001][T002][T003]
  - 書体：太めのゴシック、白文字＋濃い色の縁取り [A001][A002][T001][T002][T003]
  - **縁取りの色は動画ごとに見やすさで選ぶ**（固定色なし。背景の映像に埋もれない色にする。例：A001は紺、A002は濃いピンク、T001は黒、T002はマゼンタ、T003は赤）（ユーザー確認済み） [A001][A002][T001][T002][T003]
  - 出し方：Vrew の文字エフェクト（小→拡大しながら出現） [A001][A002][T001][T002][T003]
  - 位置は全編固定・中央揃え [A001][A002][T001][T002][T003]
  - **高さは動画ごとに見やすい位置を選ぶ**（固定値なし。素材の顔や文字に重ならない所。例：A001は約60%、A002は約45%）（ユーザー確認済み） [A001][A002]

## ai-voice

### 制作環境
- 声：**雨晴はう**（VOICEVOX にもある） [A001][A002]

### 台本の書き方
- 台本は**普通の文章で書く**（Vrew に入れる前の状態）。テロップ1枚ごとの区切りは Vrew に入れてから作る（ユーザー確認済み） [A002]
  - A001 の台本.txt は空行区切りになっていたが、これは区切った後の形
- 最終的には**テロップ1枚＝音声1フレーズ**、1枚は最大2行・1行あたり約5〜12字。意味の切れ目で区切る（「こういった」だけの1枚もあり） [A001][A002]
- 台本は一字一句そのまま読ませる（読み替えなし） [A001][A002]
- **読ませる文とテロップの文字は別に直してよい**：テロップ側だけで「〜か。」→「〜か？」、「1,000万超」→「1,000万超え」と修正している（ユーザー確認済み） [A002]
- **人名などの固有名詞は素材画像（番組テロップ・SNS）の表記と照合する**（A002 は「冬條」を「東條」と誤記した） [A002]
- 尺：テロップ1枚平均約2秒（A001：44秒・20枚、A002：23秒・12枚） [A001][A002]

### 構成（暫定）
**プロフィール型** [A001]
1. **フック**：名前より先に「すごい肩書き＋見た目の魅力」で引く（例：「ルイ・ヴィトンのアンバサダーを務める／驚くほど美しい男性」）
2. **正体**：所属 → 名前
3. **プロフィール**：出身・生年月日・ビジュアルの特徴
4. **実績**：年号付きで時系列に（「そして2023年には」「2024年には」）
5. **人柄**：ギャップ（ステージ／普段）
6. **締め**：「これからも目が離せません」系

**話題型**（エピソード1つだけ・短め） [A002]
1. **フック**：所属＋名前＋「〜すぎると話題になっています」
2. **エピソード**：「なんと、〜」
3. **意味づけ**：そのエピソードのすごさを一般論で言う
4. **締め**：世間の反応「〜と称賛の声が上がっています」

### 映像
- 素材は対象人物の**映像クリップ**か**静止画**（番組画面・SNSのスクショ・他媒体のスクショ）。静止画のときは動き（ズーム・パン）なし [A001][A002]
- 素材の元音声は使わない [A001]
- 映像クリップ：縦長でない素材は拡大して画面いっぱいにする（黒帯なし） [A001]
- 静止画：**横幅いっぱいに置いて、縦の余りは黒**（暫定） [A002]
  - 2枚組の画像は左右に切り分けて別カットにする [A002]
- 切り替えはカット（トランジションなし） [A001][A002]
- 静止画のときは**文の切れ目で切り替え、話している中身に合う画像を出す**（所属の話→番組画面、DMの話→DM画面）。映像クリップのとき（A001）は素材の区切りで切り替えていた [A001][A002]
- **クリップの使い回しは避けたい**。素材の合計時間はナレーション尺以上を確保する（A001は不足で2回使用） [A001]
- **素材に元から焼き込まれた字幕・文字は消す**（ぼかし・トリミング等）。テロップと重なって読みにくくなる（A002 は消し忘れ）（ユーザー確認済み） [A002]
  - ※A002 冒頭のタイトル「鬼努力ホスト」はその動画だけ。型にしない [A002]

### 音声
- フレーズ間に約0.4秒の間 [A001][A002]

## talk

### 撮影
- スマホ（iPhone）縦撮り、1テイク撮りっぱなし。言い直し・撮り直しは撮影中にその場でやり、編集で選ぶ [T001][T002][T003]

### カット編集
- 残る長さは結果であって目標値はない（T001：237秒→112秒＝47%、T002：226秒→135秒＝60%、T003：76秒→40秒＝53%）。下のルールで不要な部分を削り切った結果が完成尺 [T001][T002][T003]
- **言い直し・撮り直しは、最後のテイク／言い切れている方を採用**（T003：「騙し取って」→言い直した「騙し取ったという」） [T001][T003]
- 言いかけてやめた文、何度言い直しても着地しなかった部分は丸ごと削る（T002：約20秒分） [T001][T002][T003]
- 考え込んでいる長い無言は詰める（T002：約17秒の無言） [T002]
- 文頭のつなぎ言葉を削る：「はい」「でね」「なんか」「皆さんも」「だからもう」「別にその」など [T001]
  - T002 の「ということで」「ただどちらにしろね」、T003 冒頭の「はい」が残っているのは意図ではない（削り漏れ）。基本は削る [T002][T003]
- 文中の「あの」も削る（T003：「ホストコールのねあの皆様が」→「ホストコールの皆様が」） [T003]
- 文中でも不要な一語は削る（例：「メインは**僕**ワンワン」→「メインはワンワン」、「**若干**ネットワークビジネスのような」の「若干」） [T001][T002][T003]
- 同じ意味の繰り返し、本題からそれた話は丸ごと削る [T001]
- フレーズ間の間はほぼゼロまで詰める（0.3秒以上の無音を残さない） [T001][T002][T003]
- ジャンプカットはそのまま見せる（ズーム・トランジションでごまかさない）。2〜3秒に1回程度 [T001][T002][T003]
- 再生速度・色は元のまま [T001][T002][T003]

### 構成（暫定）
**呼びかけ・意見型** [T001]
1. **フック**：届けたい相手を名指しで呼ぶ（「〜しようと思ったけど、やっぱり辞めてしまったあなたへ」）
2. **現状＋自分の気持ち**
3. **初心を思い出させる**
4. **主張**
5. **たとえ話**（身近な例：修学旅行のバスガイド）
6. **提案**
7. **行動の呼びかけ**で終わる（「ご連絡いただければ嬉しいです」）

**ニュース・事実提示型** [T002][T003]
1. **フック**：事実から入る（「今、動物虐待問題が増加の一途をたどっています」「新たな頂き女子が逮捕されました」）
2. **詳細・原因**（数字を入れる：13人から総額3000万円）
3. **問題点・自分の意見**
4. **提案**で終わる（「〜を考えていただけるといいのかなって思いますね」）

### 画面
- 話者映像を顔のアップに拡大トリミング（T001は顔〜胸、T002は頭頂〜口元まで寄る） [T001][T002][T003]
- **図解・告知画像があるときは上下2分割の型**（ユーザー確認済み） [T001][T002][T003]
  - 上段：話者（画面の上約44〜52%）＋テロップ（上段の下寄り）
  - 下段：画像を横幅いっぱいで表示。画像1枚なら全編固定（T002は正方形 1080x1080）
  - **画像が複数あるときは、話題に合わせて下段の画像を切り替える**（T003：容疑者のニュース→ホストクラブのニュース→名前を出した人物の画面）（ユーザー確認済み） [T003]
  - 下段の高さは画像の縦横比しだいで多少変わってよい（横幅いっぱいが優先） [T003]
  - 下段のタイトル文字は画像しだい（T001は告知チラシに日付入りイベント名を追加、T002は画像に見出し入りなので無し）
  - 下段の画像は **ChatGPT で作る図解**でも、**ニュース画面などのスクショ**でもよい（話に合う方）（ユーザー確認済み） [T002][T003]
  - 図解は ChatGPT で画像生成（T002：1254x1254 の正方形、見出し付きの3パネル構成） [T002]
  - スクショに焼き込まれた他媒体のタイトル等は切り抜いて使わない（T003：他媒体ショートの上下の文字を除いて真ん中だけ使用） [T003]
  - 図解の中身は話の要点の順に並べる（T002：検挙件数→グループの仕組み→心理） [T002]

### テロップ
- **話した言葉をそのまま字幕にする**（要約しない）。カットした言葉は字幕にも出さない [T001][T002][T003]
- 1行あたり約5〜9字 [T001][T002][T003]
- 固有名詞は正しい表記に直す（音声「ワンワン」→ 字幕「旺旺」、T003：「川村玲音容疑者」「溝口勇児」） [T001][T003]
- 切り替えは話のフレーズに同期 [T001][T002][T003]

### 音声
- 話者の地声のみ。音量を約+4dB 持ち上げる（T001：-32.3→-28.5dB、T002：-33.6→-29.3dB、T003：-30.8→-27.1dB） [T001][T002][T003]
