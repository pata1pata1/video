## ai-voice

### 制作環境
- 編集：**Vrew**、声：**雨晴はう**（VOICEVOX にもある） [001]
- 書き出しは**ナレーションのみ**。BGM は YouTube アップロード時に YouTube 側の曲を付ける（こちらで BGM を足さない） [001]

### 台本の書き方（Vrew 流し込み用）
- **空行区切り1ブロック＝テロップ1枚＝音声1フレーズ** [001]
- ブロック内の**改行＝テロップの改行**、1ブロック最大2行、1行あたり短め（〜12字程度） [001]
- 台本は一字一句そのまま読ませる（読み替えなし） [001]
- 尺：約44秒で20ブロック程度（1ブロック平均約2.2秒）（暫定） [001]

### 構成（人物紹介もの・暫定）
1. **フック**：名前より先に「すごい肩書き＋見た目の魅力」で引く（例：「ルイ・ヴィトンのアンバサダーを務める／驚くほど美しい男性」）
2. **正体**：所属 → 名前
3. **プロフィール**：出身・生年月日・ビジュアルの特徴
4. **実績**：年号付きで時系列に（「そして2023年には」「2024年には」）
5. **人柄**：ギャップ（ステージ／普段）
6. **締め**：「これからも目が離せません」系
