# 作風ガイド

各項目の末尾 `[A001]` `[T001]` は根拠になったサンプル（A＝ai-voice、T＝talk、番号はタイプ内の連番）。1本だけの根拠は「暫定」。複数本で確認できたら確定扱いにする。

## 共通

- 縦型 1080x1920 / 30fps（素材が60fpsでも30fpsで書き出す） [A001][T001][T002]
- 編集ソフトは **Vrew** [A001][T001][T002]
- 書き出しは**声のみ**。BGM はアップロード時にプラットフォーム側の曲を付ける（こちらで BGM・効果音を足さない） [A001][T001][T002]
- **締めの挨拶（「ご視聴ありがとうございました」等）は入れない**。本題の最後の一言で終わる（ショート動画の方針） [T001][T002]
  - ※T002 の最後の黒背景エンドカード（文字だけの一言）はその動画だけ。型にしない [T002]
- テロップ
  - 1枚＝短いフレーズ、**最大2行**、意味の切れ目で改行 [A001][T001][T002]
  - 書体：太めのゴシック、白文字＋濃い色の縁取り [A001][T001][T002]
  - **縁取りの色は動画ごとに見やすさで選ぶ**（固定色なし。背景の映像に埋もれない色にする。例：A001は紺、T001は黒、T002はマゼンタ）（ユーザー確認済み） [A001][T001][T002]
  - 出し方：Vrew の文字エフェクト（小→拡大しながら出現） [A001][T001][T002]
  - 位置は全編固定・中央揃え [A001][T001][T002]

## ai-voice

### 制作環境
- 声：**雨晴はう**（VOICEVOX にもある） [A001]

### 台本の書き方（Vrew 流し込み用）
- **空行区切り1ブロック＝テロップ1枚＝音声1フレーズ** [A001]
- ブロック内の**改行＝テロップの改行**、1行あたり短め（〜12字程度） [A001]
- 台本は一字一句そのまま読ませる（読み替えなし） [A001]
- 尺：約44秒で20ブロック程度（1ブロック平均約2.2秒）（暫定） [A001]

### 構成（人物紹介もの・暫定）
1. **フック**：名前より先に「すごい肩書き＋見た目の魅力」で引く（例：「ルイ・ヴィトンのアンバサダーを務める／驚くほど美しい男性」）
2. **正体**：所属 → 名前
3. **プロフィール**：出身・生年月日・ビジュアルの特徴
4. **実績**：年号付きで時系列に（「そして2023年には」「2024年には」）
5. **人柄**：ギャップ（ステージ／普段）
6. **締め**：「これからも目が離せません」系
[A001]

### 映像
- 対象人物の映像クリップのみで構成（画像スライドではない） [A001]
- 縦長でない素材は拡大して画面いっぱいにする（黒帯なし） [A001]
- カットは素材の区切りで切り替え、ナレーションとは揃えない（暫定） [A001]
- 素材の元音声は使わない [A001]
- **クリップの使い回しは避けたい**。素材の合計時間はナレーション尺以上を確保する（A001は不足で2回使用） [A001]

### テロップ
- 位置：中央よりやや下（高さ約60%） [A001]

### 音声
- フレーズ間に約0.4秒の間 [A001]

## talk

### 撮影
- スマホ（iPhone）縦撮り、1テイク撮りっぱなし。言い直し・撮り直しは撮影中にその場でやり、編集で選ぶ [T001][T002]

### カット編集
- 残る長さは結果であって目標値はない（T001：237秒→112秒＝47%、T002：226秒→135秒＝60%）。下のルールで不要な部分を削り切った結果が完成尺 [T001][T002]
- **言い直し・撮り直しは、最後のテイク／言い切れている方を採用** [T001]
- 言いかけてやめた文、何度言い直しても着地しなかった部分は丸ごと削る（T002：約20秒分） [T001][T002]
- 考え込んでいる長い無言は詰める（T002：約17秒の無言） [T002]
- 文頭のつなぎ言葉を削る：「はい」「でね」「なんか」「皆さんも」「だからもう」「別にその」など [T001]
  - T002 で「ということで」「ただどちらにしろね」が残っているのは意図ではない（削り漏れ）。基本は削る [T002]
- 文中でも不要な一語は削る（例：「メインは**僕**ワンワン」→「メインはワンワン」、「**若干**ネットワークビジネスのような」の「若干」） [T001][T002]
- 同じ意味の繰り返し、本題からそれた話は丸ごと削る [T001]
- フレーズ間の間はほぼゼロまで詰める（0.3秒以上の無音を残さない） [T001][T002]
- ジャンプカットはそのまま見せる（ズーム・トランジションでごまかさない）。2〜3秒に1回程度 [T001][T002]
- 再生速度・色は元のまま [T001][T002]

### 構成（呼びかけ・意見もの・暫定）
1. **フック**：届けたい相手を名指しで呼ぶ（「〜しようと思ったけど、やっぱり辞めてしまったあなたへ」）
2. **現状＋自分の気持ち**
3. **初心を思い出させる**
4. **主張**
5. **たとえ話**（身近な例：修学旅行のバスガイド）
6. **提案**
7. **行動の呼びかけ**で終わる（「ご連絡いただければ嬉しいです」）
[T001]

### 画面
- 話者映像を顔のアップに拡大トリミング（T001は顔〜胸、T002は頭頂〜口元まで寄る） [T001][T002]
- **図解・告知画像があるときは上下2分割の型**（ユーザー確認済み） [T001][T002]
  - 上段：話者（画面の上約44〜52%）＋テロップ（上段の下寄り）
  - 下段：画像を横幅いっぱいで全編固定表示（T002は正方形 1080x1080）
  - 下段のタイトル文字は画像しだい（T001は告知チラシに日付入りイベント名を追加、T002は画像に見出し入りなので無し）
  - 図解は **ChatGPT で画像生成**して作る（T002：1254x1254 の正方形、見出し付きの3パネル構成）（ユーザー確認済み） [T002]
  - 図解の中身は話の要点の順に並べる（T002：検挙件数→グループの仕組み→心理） [T002]

### テロップ
- **話した言葉をそのまま字幕にする**（要約しない）。カットした言葉は字幕にも出さない [T001][T002]
- 1行あたり約5〜9字 [T001][T002]
- 固有名詞は正しい表記に直す（音声「ワンワン」→ 字幕「旺旺」） [T001]
- 切り替えは話のフレーズに同期 [T001][T002]

### 音声
- 話者の地声のみ。音量を約+4dB 持ち上げる（T001：-32.3→-28.5dB、T002：-33.6→-29.3dB） [T001][T002]
