## ニュースショート動画（上部字幕固定型）

ニュース系ショート（事件・炎上・時事ニュース・話題解説）の**標準の型**。ニュース系はまずこの型を使い、特別な理由がない限り下部字幕ではなく上部字幕固定にする（ユーザー指定） [N001]
- 形式：ai-voice（AI音声ナレーション＋画像）。話者が映る talk のニュース型（T002・T003）は、これまでどおり talk の上下2分割を使う
- 制作：`templates/news-short-top/` をコピーして作る（Remotion・VOICEVOX・字幕同期・書き出しまで入っている）。手順はテンプレートの README
- 共通ルール（声のみ・締めの挨拶なし・テロップの書体と出し方）はそのまま

### 画面構成（1080x1920・9:16）
```
┌──────────────┐ 0
│   字幕専用帯     │ 60〜300px（目安）：字幕だけ。暗め・シンプルな背景
├──────────────┤
│   画像内見出し     │ 中段：見出しは字幕帯の下から始める
│ メインビジュアル・補足 │ 下段
└──────────────┘ 1920
```

### 字幕
- 位置は**画面上部に固定**：中心 X=540・Y=175。**全カット共通・画像ごとに変えない・自動で上下に動かさない**。字幕帯の外には出さない [N001]
- 最大2行・中央揃え。長い1行は文字を小さくして帯に収める（最大72px） [N001]
- 「、」「。」は表示しない（「？」「！」は残す）。読ませる文とテロップの文字は別に直してよい（ai-voice と同じ） [N001]
- 書体・縁取り・出し方は共通のテロップと同じ（太いゴシック、白文字＋濃い色の縁取り、小→拡大で出現） [N001]
- 1枚＝音声1フレーズ。開始時刻は VOICEVOX のモーラ長から計算し、faster-whisper で声とのズレを確認する（N001：最大0.12秒） [N001]

### 画像
- **画像は最初から「上部字幕帯あり」で作る**。字幕帯（上から60〜300px）に見出し・重要情報・顔・主役要素を置かない [N001]
- 全画像で字幕帯の高さ・位置・余白をそろえる（N001：字幕枠 x44〜1036・y45〜295、画像パネル x107〜973・y330〜1875） [N001]
- 字幕帯の下に「画像内見出し → メインビジュアル・補足」の順に置く [N001]
- 下端付近と右端には YouTube ショートの UI（タイトル・チャンネル名・ボタン）が重なるので、重要情報を置かない（範囲は目安。投稿後に実機で確認する） [N001]
- 秒数や編集用の文字は入れない [N001]

### 動き・切り替え
- 字幕帯と画像パネルの外枠は動かさず、**パネルの内側だけ**をゆっくりズーム（1.00〜1.04倍）・小さくパンする。画像内の文字が切れない範囲に収める [N001]
  - ※ai-voice の「静止画は動きなし・切り替えはカット」[A002] とは別。ニュースショートはこちらを使う
- 画像の切り替えはクロスフェード（約0.33秒）。話している中身に合う画像を、文の切れ目で出す [N001]

### 声・音
- 声は案件ごとに指定（N001：VOICEVOX 青山龍星 ノーマル ID13・速度1.12）。文と文の間は約0.4秒 [N001]
- BGM・効果音なし（共通ルール）。音量は -14 LUFS 前後 [N001]

### 確認（書き出し後）
- 全場面のコマを抜き出し、字幕位置・字幕帯からのはみ出し・画像内の文字切れ・見出しとの重なりを見る
- 字幕と声のズレ・尺・音量を測る

## ai-voice

### 制作環境
- 声：**雨晴はう**（VOICEVOX にもある） [A001][A002]
  - ※ニュースショートは案件ごとに指定（N001は青山龍星） [N001]

### 台本の書き方
- 台本は**普通の文章で書く**（Vrew に入れる前の状態）。テロップ1枚ごとの区切りは Vrew に入れてから作る（ユーザー確認済み） [A002]
  - A001 の台本.txt は空行区切りになっていたが、これは区切った後の形
- 最終的には**テロップ1枚＝音声1フレーズ**、1枚は最大2行・1行あたり約5〜12字。意味の切れ目で区切る（「こういった」だけの1枚もあり） [A001][A002][A003]
- **読み上げた言葉はテロップに全部出す**。A003 で「ぶっ飛んでる男」がテロップから抜けたのはミス（ユーザー確認済み） [A003]
- 台本は一字一句そのまま読ませる（読み替えなし） [A001][A002]
- **読ませる文とテロップの文字は別に直してよい**：テロップ側だけで「〜か。」→「〜か？」、「1,000万超」→「1,000万超え」と修正している（ユーザー確認済み） [A002]
  - A003：「こんなこと」→「こんな事」、文末に「？」。名前はテロップ「sakkki」・読み「サキ」 [A003]
- **人名などの固有名詞は素材画像（番組テロップ・SNS）の表記と照合する**（A002 は「冬條」を「東條」と誤記した） [A002]
- 尺：テロップ1枚平均約2秒（A001：44秒・20枚、A002：23秒・12枚、A003：34秒・18枚で約1.7秒） [A001][A002][A003]

### 構成（暫定）
**プロフィール型** [A001]
1. **フック**：名前より先に「すごい肩書き＋見た目の魅力」で引く（例：「ルイ・ヴィトンのアンバサダーを務める／驚くほど美しい男性」）
2. **正体**：所属 → 名前
3. **プロフィール**：出身・生年月日・ビジュアルの特徴
4. **実績**：年号付きで時系列に（「そして2023年には」「2024年には」）
5. **人柄**：ギャップ（ステージ／普段）
6. **締め**：「これからも目が離せません」系

**話題型**（エピソード1つだけ・短め） [A002]
1. **フック**：所属＋名前＋「〜すぎると話題になっています」
2. **エピソード**：「なんと、〜」
3. **意味づけ**：そのエピソードのすごさを一般論で言う
4. **締め**：世間の反応「〜と称賛の声が上がっています」

**事件・ニュース型**（事件映像を見せる） [A003]
1. **フック**：所属＋名前＋何が起きたか（「ブレイキングダウンsakkki選手のバー襲撃映像が公開されました」）
2. **映像の説明**：「そこに映っていたのは、〜」と、映っている中身を言葉で追う
3. **意味づけ**：「〜として有名な〜ですが、こんなことをして大丈夫なのでしょうか」
4. **今後**：「今後〜への影響が出てくると思いますが」
5. **締め**：**視聴者への問いかけ**「あなたは〜してほしい？」（コメントを誘う）

### 映像
- 素材は対象人物の**映像クリップ**か**静止画**（番組画面・SNSのスクショ・他媒体のスクショ）。静止画のときは動き（ズーム・パン）なし [A001][A002]
  - ※ニュースショートはパネル内の軽いズーム・パンとクロスフェードを使う（上記） [N001]
- 素材の元音声は使わない [A001]
  - ただし**事件映像（防犯カメラなど、現場の音に意味がある素材）は元の音を小さく残す**（A003：元の音量から約-6dB、ナレーションの下に流す）（ユーザー確認済み） [A003]
- 映像クリップ：縦長でない素材は拡大して画面いっぱいにする（黒帯なし） [A001]
- 静止画：**横幅いっぱいに置いて、縦の余りは黒**（暫定） [A002]
  - 2枚組の画像は左右に切り分けて別カットにする [A002]
- **事件映像＋本人の写真の上下2分割**（事件映像があるときの型）（ユーザー確認済み） [A003]
  - 0〜約480px：黒帯。テロップはこの帯の下寄りに置く（2行目が映像の上端に少しかかってよい）
  - 約480〜1230px：事件映像。横長素材を高さに合わせ、左右を少し切る
  - 1230〜1920px：本人の写真。横幅いっぱい、上下を切って顔を中心に
  - 全編この形のまま。映像は1本を切らずに流し、写真は動かさない（talk の上下2分割の ai-voice 版：話者の代わりに本人の写真）
  - ※A003 の、声が終わった後の約3秒（声・テロップなしで映像だけ）はその動画だけ。型にしない（ユーザー確認済み） [A003]
- 切り替えはカット（トランジションなし） [A001][A002]
- 静止画のときは**文の切れ目で切り替え、話している中身に合う画像を出す**（所属の話→番組画面、DMの話→DM画面）。映像クリップのとき（A001）は素材の区切りで切り替えていた [A001][A002]
- **クリップの使い回しは避けたい**。素材の合計時間はナレーション尺以上を確保する（A001は不足で2回使用） [A001]
- **素材に元から焼き込まれた字幕・文字は消す**（ぼかし・トリミング等）。テロップと重なって読みにくくなる（A002 は消し忘れ）（ユーザー確認済み） [A002]
  - ※A002 冒頭のタイトル「鬼努力ホスト」はその動画だけ。型にしない [A002]

### 音声
- フレーズ間に約0.4秒の間 [A001][A002]

### カット編集
- 残る長さは結果であって目標値はない（T001：237秒→112秒＝47%、T002：226秒→135秒＝60%、T003：76秒→40秒＝53%、T004：107秒→58秒＝54%）。下のルールで不要な部分を削り切った結果が完成尺 [T001][T002][T003][T004]

- 言いかけてやめた文、何度言い直しても着地しなかった部分は丸ごと削る（T002：約20秒分） [T001][T002][T003][T004]
- 考え込んでいる長い無言は詰める（T002：約17秒の無言） [T002]
- 文頭のつなぎ言葉を削る：「はい」「でね」「なんか」「皆さんも」「だからもう」「別にその」「特にじゃあ」「うん」「まあ」など [T001][T004]
  - T002 の「ということで」「ただどちらにしろね」、T003 冒頭の「はい」が残っているのは意図ではない（削り漏れ）。基本は削る [T002][T003]

- 同じ意味の繰り返し、本題からそれた話は丸ごと削る（T004：「27日の夕方」を2回言った片方） [T001][T004]
- フレーズ間の間はほぼゼロまで詰める（0.3秒以上の無音はほぼ残さない。残っても0.6秒未満） [T001][T002][T003][T004]
- ジャンプカットはそのまま見せる（ズーム・トランジションでごまかさない）。2〜3秒に1回程度 [T001][T002][T003][T004]
- 再生速度・色は元のまま [T001][T002][T003][T004]

### テロップ
- **話した言葉をそのまま字幕にする**（要約しない）。カットした言葉は字幕にも出さない [T001][T002][T003][T004]
- 1行あたり約5〜9字 [T001][T002][T003][T004]
- 固有名詞は正しい表記に直す（音声「ワンワン」→ 字幕「旺旺」、T003：「川村玲音容疑者」「溝口勇児」、T004：音声認識の「鈴木重弘」→開廷表どおり「鈴木成博」）。**素材の資料で表記を確かめる** [T001][T003][T004]
