# pattern-04：人物画像＋字幕（界隈まとめ・シンプル）

2026-11-16 作成。最初の動画は「溝口界隈 逮捕者まとめ」（`mizoguchi-kaiwai`）。
同じ種類のできごと（逮捕・騒動など）が何人も続く話題を、**人物の写真と大きな字幕だけ**で時系列に紹介する型。

最初は「ニュース速報型」として、映像の枠・人物の一覧・速報テロップ・カードを同時に出していた。ユーザーの指摘（「人物画像と字幕主体のシンプルな構成で大丈夫。視聴者が見て疲れない事が大事」）を受けて、同じ日にこの形へ作り直した。**画面に要素を足さないこと**がこの型のいちばん大事なルール。

movie-trivia 全体の制作ルール（事実確認・出典・素材確認・書き出し）は `../../common/` にあり、このパターンもそれに従う。

## 画面（`src/news.tsx`）

1. **画像1枚を画面いっぱいに**
   - 人物の写真は、ぼかした同じ写真の上に全体をはっきり見せ、少しずつ寄る
   - 映像（Pexels など）は全画面に、少し暗くして出す
2. **左上の小さな札**
   - 人物なら「年月｜名前」と「容疑 → その後」（処分の色つき）
   - それ以外は見出し（`headline`）
3. **右上に小さく出典**：「出典：〇〇」。イメージ映像なら「※映像はイメージです」
4. **下に大きな字幕**
   - 白の極太72px・黒い縁取り。22字を超えたら「、」で2行に分ける
   - 2行に入らない文は、文ごとに分けて出す。はみ出す行は自動で小さくする
5. **エンディング**：左下に VOICEVOX のクレジット

これ以外のもの（一覧・テロップ・ヘッダー・カード）は出さない。

## 人物・事件を扱うときのルール

- 事実は報道・公的資料で確かめ、どれで確かめたかを投稿メモの事実確認表に書く。1つの媒体でしか確かめられないことは、使わないか「〇〇によると」と言う
- **逮捕は有罪ではない**：冒頭でそう言う。札の「その後」には、処分（有罪・起訴・不起訴・捜査中・続報なし）を必ず書く
- **界隈の名前になっている人（中心人物）を、容疑者のように見せない**：容疑がないなら冒頭でそう言う
- 名前と写真の扱いは動画ごとにユーザーと決め、決めたことを投稿メモに書く
- **人物の写真は、本人だと確かめられたものだけ使う**
  - 確かめ方：記事のキャプション・ファイル名・本人の名前が写った背景など
  - 集合写真や、誰か分からない写真は使わない
  - 1本目では、og:image がサップ西成だった画像を「ダイスケ」と取り違えかけ、ローランドの画像を溝口さんと取り違えかけた
- 写真は報道記事の代表画像（og:image）を使い、台帳 `asset-sources.json` に次のように入れる
  - `provider: "web"`、`usageType: "documentary"`
  - `onScreenCredit` に「出典：〇〇」。本人のSNSの画像なら「出典：本人のInstagram（〇〇より）」

## 台本

- 台本の最上位に、一覧の人を `roster` で書く：
  `{ "id": "shoyu", "date": "2023.07", "name": "醤油ニキ", "role": "BreakingDown 出場", "charge": "傷害", "status": "dropped", "result": "不起訴（本人が報告）", "source": "デイリースポーツ" }`
  - `status`：`guilty`（有罪）／`trial`（起訴）／`dropped`（不起訴）／`open`（捜査中）／`unknown`（続報なし）
- 文の `visual`：

| 書き方 | 画面 |
|---|---|
| `{ "footage": "<キー>" }` | 画像を替える（札は消える） |
| `{ "footage": "p_<人>", "profile": "<roster の id>" }` | 人物の写真と名前の札 |
| `{ "headline": { "title": "…", "sub": "…" } }` | 左上に見出しの札 |
| `{ "clear": true }` | 札を消す |

- 札は、次の札・`clear`・`footage` だけの文まで出しっぱなし
- 人物の説明が続く文には `visual` を書かない（写真と札が残る）
- 1文目には `footage` が必要
- 台本にある `reveal`・`ticker`・`stat`・`points` は、この型では画面に出ない（読み上げと字幕だけ）

## サムネイル（ユーザーの見本 `image/サムネイル見本.png`、2026-11-16）

- **上**：人物の顔写真を横に4枚並べる。間は斜めの細い隙間
- **下**：黒地に大きな文字3段
  1. 赤い帯の上に黄色の一言（`kicker`。例：「また逮捕!?」）
  2. 白の縁取り文字（`lines`。例：「溝口界隈から」）
  3. 赤の特大・白の縁取り（`accent`。例：「逮捕者が止まらない」）
- 台本の書き方：`thumbnails` の項目に `faces: [{ "key": "p_asun", "position": "center 30%" }, …]`・`kicker`・`lines`・`accent` を書く（描画は `src/Thumbnail.tsx` の `FacesThumbnail`）
- 見本にある手錠の絵は入れていない（逮捕＝有罪と見えるのを避けるため。ユーザーが望めば足す）

## 設定ファイル

| ファイル | 内容 |
|---|---|
| `config.json` | 構成（オープニング → 章 × N → エンディング）。フェード10コマ |
| `design.json` | `news`：写真の位置、映像の暗さ、札の位置と文字の大きさ、処分の色（`status`）、字幕の位置 |
| `subtitle.json` | 字幕の大きさ・行の分け方 |
| `voice.json` | 青山龍星 ノーマル（ID 13）、速さ1.05（2026-11-16 ユーザー指定） |
| `bgm.json` | 標準はBGMなし |
| `thumbnail.json` | 元の型（映像を全面に敷く形）の設定。`faces` のある項目は見本の形で描く |
| `script-template.json` | 台本の雛形 |
