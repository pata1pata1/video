# pattern-02：ランキング・カウントダウン（近未来HUD）

10位から1位へ順に紹介するランキング動画の型（2026-10-23 作成。最初は明るいポップで作り、同日に近未来風へ変えた）。
書き出しは共通の基盤（`common/render.md`）を使う。
テーマ・台本・素材・図解の中身は含まない（それは動画ごとに作る）。

movie-trivia 全体の制作ルール（事実確認・出典・素材確認・書き出し）は `../../common/` にあり、このパターンもそれに従う。

## 順位の根拠

- **順位は出典のある指標で決める**（統計の数値、公的機関や調査会社のランキングなど）。指標と出典はオープニングで言い、投稿メモの事実確認表にも書く
- 指標がなく順位を付けられないテーマは、このパターンにしない（このパターンにはしない）
- 同じ値で並んだ順位は、出典の扱いに合わせる（同率なら台本でもそう言う）

## 設定ファイル

| ファイル | 内容 |
|---|---|
| `config.json` | 構成：オープニング → 順位 × N → エンディング。1順位4〜7文、ランキング表の出し方 |
| `design.json` | 近未来HUD：濃紺に細いグリッドと青い光、シアン（強調）＋マゼンタ（対比）のネオン発光。本文は Zen Kaku Gothic New、数字と英字は Orbitron。角を斜めに切ったパネル、画面四隅のブラケット、タイトルの回転リングと走査線、順位のリング（1〜3位は金・銀・銅）、ランキング表、左上の「◯位」ラベル |
| `subtitle.json` | 濃紺の地に白文字、シアンの細い枠線と淡い発光 |
| `voice.json` | 春日部つむぎ ノーマル（ID 8）、速さ1.0 |
| `bgm.json` | BGMなし・効果音なし（台本で指定すれば使える） |
| `render.json` | 共通の書き出し基盤に渡す設定（JPEG画質、x264、-16 LUFS / -1.5 dBTP） |
| `thumbnail.json` | 映像を全面に敷き、縁取り文字＋強調語＋帯・丸バッジのレイアウトで、色をマゼンタ（帯・バッジ）とシアン（強調語）にしたもの。1位の答えはサムネイルで明かさない |
| `script-template.json` | 台本の雛形（10位・2位・1位の例。間の順位は同じ形で足す） |

## 動画の構成

- オープニング → 順位 × N → エンディング。**順位はシーンの `kind: "chapter"`、`number` が順位**。台本には大きい順位から書く（10, 9, …, 1）。10位からが基本だが、テーマに合わせて5位・7位からでもよい
- 尺は6〜8分が目安。1順位30〜40秒（4〜7文）、1位だけは長めにしてよい
- **オープニング**：タイトル（映像に重ねる）→ 印象的な数字か、順位を決めた指標と出典 → ランキング表（全部「？？？」）→「第1位は最後に」
- **各順位の1文目**は順位カード（回転するリングの中に「RANK 10」＋見出し＋10〜1の進み具合。`scene.footage` の映像を濃紺で暗くした背景）。この文で「第10位は、〇〇です」と言う。順位の中は左上に「10位 見出し」
- 順位の中は映像・数字カード（順位の根拠の数字）・箇条書き・図解を使う。図解は `step` で2〜5段階
- **ランキング表**（`{ "board": true }`）は、オープニング・2位の最後（残るは1位）・エンディングの1文目に出す。それまでに紹介した順位だけ見出しが開く（その順位の2文目以降で出せば、その順位も開く）
- **エンディング**は3文。1文目でランキング表を出して振り返り、2文目で「コメント」、3文目で「高評価」「チャンネル登録」ボタン。VOICEVOXのクレジットを表示

## 1場面あたりの情報量

1文＝1字幕（約56字まで）、同じ映像は1〜3文、数字カードは1枚に数字1つ、箇条書きは4項目まで。
ランキング表の見出し（`heading`）は、1行に収まる長さ（約14字まで）にする。

## 画面指定（台本の `visual`）

| 書き方 | 画面 |
|---|---|
| `{ "title": true, "footage": "<キー>" }` | タイトル画面 |
| `{ "footage": "<キー>" }` | 映像を全画面表示（クレジット付き） |
| `{ "stat": { "value", "unit", "label" }, "footage": "<キー>" }` | 数字カード（footage があれば映像に重ねる） |
| `{ "diagram": "<名前>", "step": n }` | 図解（`src/videos/<id>/diagrams.tsx` に動画ごとに作る） |
| `{ "points": { "title": "...", "items": [...] } }` | 箇条書きカード |

加えて：

| 書き方 | 画面 |
|---|---|
| `{ "board": true }` | ランキング表。見出しは `titleMain`。1〜5位を左、6〜10位を右に並べる |

指定がない文は前の画面を続ける。画面は文の0.4秒前に切り替わり、10コマのフェードで重なる。

## 見た目の部品（コード）

HUDの部品は `src/hud.tsx`（`Box`＝角を切ったパネル、`Brackets`、`ScanLine`、`Rings`、`TitleRings`）。どれも design.json の `hud`・`panel`・`glow`・`paper` があるときだけ効き、pattern-03 の見た目は変わらない。

## 図解の作り方

図解の中身は動画ごとに `src/videos/<id>/diagrams.tsx` に書く（共通の部品は `src/diagram-kit.tsx`：`useSteps`・`Svg`・`T`・`Card`）。背景は濃紺のグリッドになり、`Card` は濃紺、文字は白になる。配色は `color.accent`（シアン）と `color.cool`（マゼンタ）だけを使う。

## チャプター

`node scripts/chapters.mjs --script=<id>` は「第10位 見出し」の形で出す。

## 動画ごとに決めること（パターンでは決めない）

テーマ、順位を決める指標と出典、順位の数、各順位の見出しと中身、映像素材（`media` のキーと検索語）、図解、読み替え表、タイトル、サムネイルの文言。
