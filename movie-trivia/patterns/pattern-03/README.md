# pattern-03：事件解説・ダーク（結末→経緯）

実際の事件を、結末（判決）から入って経緯を時系列でたどる解説動画の型（2026-10-25 作成）。
参考にしたのは、人が出演する事件解説のトーク番組（あるごめとりい）の「再現映像＋光るキーワード」の部分の雰囲気。出演者のトークは、ナレーション1人（VOICEVOX）に置き換えた。
書き出し・映像の出し方・1場面の情報量は pattern-01 と同じ。テーマ・台本・素材・図解の中身は含まない（それは動画ごとに作る）。

movie-trivia 全体の制作ルール（事実確認・出典・素材確認・書き出し）は `../../common/` にあり、このパターンもそれに従う。

## 事件を扱うときのルール

- **事実は判決文・公的資料・複数の報道で確かめる**。報道より一次情報（判決、裁判所・警察・検察の発表）を優先し、どれで確かめたかを投稿メモの事実確認表に書く
- **確定判決があるかを最初に確かめる**。裁判中・無罪を主張している人を犯人と断定しない（「〜とされる」「検察は〜と主張」と書き分ける）
- 動機・心理は、判決や本人の発言で認められた範囲だけを言う。推測で人物を評価しない（「サイコパス」「怪物」などの言葉は使わない）
- **実名は、その事件の日本語版ウィキペディアの記事に載っている人だけ使う**（2026-10-25 ユーザーが決めた基準）。載っていない人は「偽の地主役の女」「主犯格とされた男」のように役割で呼ぶ。報道や会社の報告書に名前があっても、ウィキペディアになければ使わない。確認した記事は投稿メモに書く
- 本人や被害者の写真・報道映像の静止画を使うかは、動画ごとにユーザーと決める（6本目と同じく、権利の申し立てのリスクがある）
- 被害者と遺族を傷つける描写（遺体・凶器・血）は映像でも言葉でも見せない。再現映像は Pexels の「それらしい」映像（夜の道・病室・手元など）で、実物と誤解されない使い方にする

## 動画の構成

- オープニング → 章 × N → エンディング。章は経緯を時系列に分けたもの（発端・事件・捜査・裁判・動機など）。章の数はテーマに合わせて決める
- **オープニング（約40秒）**：タイトル（映像に重ねる。「もし〜だったら？」や、いつ・どこで何が起きたか）→ **結末**（判決・刑の重さを数字カードかキーワードで。確定しているかも言う）→ **謎**（なぜそうなったのか）→「事件の始まりからたどります」
- **各章の1文目**は章タイトル（「第1章」＋見出し。`scene.footage` の映像を暗くした背景）。章の中は右上に赤い筆の線で見出し
- 章の中は時系列。映像＋キーワードを中心に、日付・人物関係は図解、判決が認めた事実は箇条書き。章の最後の文で次の章へ引っぱる
- **エンディング**は3文。1文目で事件を振り返り（判決と、そこから分かること）、2文目で「コメント」、3文目で「高評価」「チャンネル登録」ボタン。VOICEVOXのクレジットを表示

## 1場面あたりの情報量

pattern-01 と同じ：1文＝1字幕（約56字まで）、同じ映像は1〜3文、数字カードは1枚に数字1つ、箇条書きは4項目まで。
キーワードは1文に1〜3語、1語は約8字まで（明朝の112pxで画面の半分に収まる長さ）。

## 画面指定（台本の `visual`）

pattern-01 の書き方（`title` / `footage` / `stat` / `diagram` / `points`）に加えて：

| 書き方 | 画面 |
|---|---|
| `{ "footage": "<キー>", "words": ["語1", "語2"] }` | 映像の上にキーワードを順に浮かべる（赤・紫・水色の順）。1語なら中央、2語は左上と右、3語は左上・右・左下 |
| `{ "words": ["語"] }` | 前の文の映像のまま、キーワードだけ替える |

写真の素材（`.jpg`）は、ぼかした同じ写真の上に枠付きで全体を見せる（人物や資料が切れない）。映像の素材は全画面で、ぼかし・粒子・傷・周辺減光を重ねる。
指定がない文は前の画面を続ける。画面は文の0.4秒前に切り替わり、14コマのフェードで重なる。

## 見た目の部品（コード）

`src/film.tsx`：`FilmOverlay`（粒子・傷・ちらつき・周辺減光）、`Words`（光るキーワード）、`BrushTag`（右上の章見出し）。どれも design.json の `film`・`words`・`chapterTag.style` があるときだけ効き、pattern-01・02 の見た目は変わらない。

## 図解の作り方

pattern-01 と同じ（`src/videos/<id>/diagrams.tsx`、共通の部品は `src/diagram-kit.tsx`）。背景は黒に赤い光、文字は白の明朝。配色は `color.accent`（赤）と `color.cool`（紫）だけを使う。時系列（日付と出来事）と人物関係の図が向いている。

## 動画ごとに決めること（パターンでは決めない）

テーマ（事件）、確かめた資料と出典、実名・写真を使うか、章の数と見出し、各文のキーワード、映像素材（`media` のキーと検索語）、図解、読み替え表、タイトル、サムネイルの文言。
