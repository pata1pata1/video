# pattern-01：シンプル解説（映像＋図解）

fusion-magnet（2026-10-06 完成版）で決まった「作り方・見た目・音・演出の型」。
テーマ・台本・素材・図解の中身は含まない（それは動画ごとに作る）。

movie-trivia 全体の制作ルール（事実確認・出典・素材確認・書き出し）は `../../common/` にあり、このパターンもそれに従う。

## 設定ファイル

| ファイル | 内容 |
|---|---|
| `config.json` | 画面サイズ・fps、動画の構成（尺の目安・章は可変）、1場面の情報量、トランジション、映像の出し方 |
| `design.json` | 配色・フォント・シンプルデザイン（HUDなし）、タイトル画面・章タイトル・章ラベル・数字カード・箇条書きカード・エンディングの寸法 |
| `subtitle.json` | 字幕の見た目と改行ルール |
| `voice.json` | VOICEVOX 話者（青山龍星 ノーマル・ID 13）、速さ1.0、間の取り方 |
| `bgm.json` | BGMなし・効果音なし（使う場合の書き方） |
| `render.json` | 共通の書き出し基盤に渡す設定（JPEG画質、x264、-16 LUFS / -1.5 dBTP） |
| `thumbnail.json` | サムネイルのデザイン（映像を全面に敷き、白の縁取り文字＋黄色の強調語＋赤い帯・丸バッジ。フォントは本編を継承） |
| `script-template.json` | 台本の雛形（`node scripts/new-video.mjs` がこれをコピーする） |

コードはこれらを読む：`src/pattern.ts`（デザイン・字幕・トランジション・声の名前）、`scripts/lib/video.mjs`（声・間・BGM・音量）。

## 動画の構成

- オープニング → 章 × N → エンディング。**章の数はテーマに合わせて決める**（固定しない）。尺は6〜8分が目安
- **冒頭約30秒は映像中心**：1文ごとに映像を替え、タイトルと印象的な数字は映像の上に重ねる。図解は使わない
- 各章の1文目は章タイトル（`scene.footage` の映像を暗くした背景）。章の中は左上に章ラベル
- 章の中は映像と図解を交互に。図解は `step` で2〜5段階に分けて見せる
- エンディングは3文。2文目で「コメント」、3文目で「高評価」「チャンネル登録」ボタンが出る。VOICEVOXのクレジットを表示

## 1場面あたりの情報量

- 1文 ＝ 1字幕。1文は2行に収まる長さ（約56字まで）
- 同じ映像は1〜3文で次へ。数字カードは1枚に数字1つ
- 箇条書きは4項目まで。見出しは台本で指定（`points.title`）

## 画面指定（台本の `visual`）

| 書き方 | 画面 |
|---|---|
| `{ "title": true, "footage": "<キー>" }` | タイトル画面（映像なしなら淡いグレーの背景＋オレンジの円） |
| `{ "footage": "<キー>" }` | 映像を全画面表示（右上にクレジット） |
| `{ "stat": { "value", "unit", "label" }, "footage": "<キー>" }` | 数字カード（footage があれば映像に重ねる） |
| `{ "diagram": "<名前>", "step": n }` | 図解（`src/videos/<id>/diagrams.tsx` に動画ごとに作る） |
| `{ "points": { "title": "...", "items": [...] } }` | 箇条書きカード |

指定がない文は前の画面を続ける。画面は文の0.4秒前に切り替わり、10コマのフェードで重なる。

## 図解の作り方

図解の中身は動画ごとに `src/videos/<id>/diagrams.tsx` に書く（パターン側には入れない）。
共通の部品は `src/diagram-kit.tsx`：`useSteps`（段階表示）、`Svg`（字幕の上の領域）、`T`（文字）、`Card`（白いカード）。
配色は `color.accent`（強調）と `color.cool`（対比）だけを使う。

## 動画ごとに決めること（パターンでは決めない）

テーマ、台本、章の数と見出し、映像素材（`media` のキーと検索語）、図解、読み替え表、タイトル、サムネイルの文言、出典。
