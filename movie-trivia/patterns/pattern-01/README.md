# pattern-01：公式発表まとめ・パネル（実際の映像を背景に）

2026-11-06 作成。「旺旺親子虐殺事件／中国当局公式発表まとめ」（https://youtu.be/p2-J1qmUlsk 、2026-10-30 公開、ゆたてぃ@動物警備隊）の画面を型にしたもの。
（以前の pattern-01「シンプル解説」は 2026-10-28 に削除済み。名前だけ引き継いだ別の型。古い型はコミット `06ab86c`）

元の動画との違い：背景はAI生成のイメージ画像ではなく、**ユーザーが用意するその出来事の実際の映像**。写真カードの画像も、検索で見つかるときは**実際の画像を優先**する（報道・公的機関の発表・SNSの投稿など）。見つからない場面だけ Pexels などのイメージ画像、それもなければAI生成。

movie-trivia 全体の制作ルール（事実確認・出典・素材確認・書き出し）は `../../common/` にあり、このパターンもそれに従う。

## 役割の分け方

| 誰が | 何を |
|---|---|
| ユーザー | 台本（文章）、ベース動画（実際の映像。背景に使う）。置き場所は `movie-trivia/image/`（Git管理外の提供素材置き場） |
| Claude | 台本を `script.json` に移す（文はそのまま。パネル・帯の見出しを付ける）、画像の検索と出典の記録、デザイン、書き出し、サムネイル、投稿メモ |

- 台本の文は勝手に足したり変えたりしない。事実の誤り・読み間違いに気づいたらユーザーに聞く
- 実際の画像は、コマを作る前に一覧（画像・出典・使う場面）をユーザーに見せて、残すか外すかを決めてもらう。報道や他人の写真は権利の申し立てを受けることがある
- 暴力の場面・遺体・未成年や被害者の顔がはっきり分かる画像と映像は使わないか、ぼかす（背景はもともとぼかすが、写真カードは別）

## 設定ファイル

| ファイル | 内容 |
|---|---|
| `config.json` | 構成（オープニング → 章 × N → エンディング、5〜8分）。タイトル画面・章タイトル画面・エンディング画面は出さない。フェード10コマ |
| `design.json` | `stage`：背景（ぼかし14px・暗さ0.5）、パネル（暗い半透明＋水色の細い枠）、帯、見出しの光、各パネルの文字の大きさ。フォント Noto Sans JP、色は水色 `#5AD2FF` と白 |
| `subtitle.json` | 黒い角丸の箱に白い極太86px。`chunk: true`：1文を17字までの区切りに分け、読みの長さで時間を割り振って1行ずつ出す |
| `voice.json` | 四国めたん ノーマル（ID 2）、速さ1.15（元の動画の1文目の長さに合わせた） |
| `bgm.json` | `bgm/pattern-01.mp3`（DOVA-SYNDROME などから選ぶ。ユーザーが指定しないときは候補を出す）、ナレーションより20dB下 |
| `render.json` | 共通の書き出し基盤に渡す設定（JPEG画質、x264、-16 LUFS / -1.5 dBTP） |
| `thumbnail.json` | 左6割を暗くして文字、右に主役の写真。赤い帯 → 白の縁取り文字 → 黄色の特大の強調語 → 白の補足 → 水色の問いかけ、右下に注記 |
| `script-template.json` | 台本の雛形 |

## いちばん大事なこと（2026-11-06、ユーザーの指摘）

- **ベース動画は視聴者に見せる主役の映像**。ぼかした背景や文字の下敷きにしない。台本のほとんどの文は `visual.footage`（ベース動画のカットを画面の中央にはっきり大きく。両脇は同じ映像をぼかして埋める）か、`photo`（実際の写真）で見せる
- **中央の文字パネル（見出しカード・FINDINGS・DATA・番号リスト）はほぼ使わない**。各章で多くても1回、大事な数字・当初の説明と事実の違い・本人の言葉のところだけ。文字は下の帯の短い見出しと字幕で足りる
- 元の動画（旺旺）はAI画像が中心だったので文字パネルが多かったが、実際の映像があるときはそれを見せる

## 画面の作り（3層）

1. **背景**：実際の映像を全面に、ぼかして暗く。右上に小さく出典（「背景映像：〇〇」）。台本の `background`（全体）→ 場面の `background` → 文の `visual.background` の順で替わり、24コマで重なって切り替わる
2. **パネル**（1文ごとに1つ。指定のない文は前のパネルのまま）
3. **帯と字幕**：帯は `visual.label` の文字（同じ文字が続く間は出しっぱなし）。字幕は短い区切りで1行ずつ

## 画面指定（台本の `visual`）

| 書き方 | 画面 |
|---|---|
| `{ "footage": "<キー>", "label": "帯の文字" }` | **ベース動画をそのまま見せる**（パネルなし）。キーは組み上げ済みのカット（台帳に `"composed": true`。下の「素材の入れ方」）。台帳が composed でない映像なら、ぼかした背景になる |
| `{ "photo": "<キー>", "label": "帯の文字", "background": "<同じキー>" }` | 写真カード（画像の全体を帯の上に大きく。右下に出典、イメージ画像なら「※画像はイメージです」） |
| `{ "headline": { "title": "見出し", "sub": "補足" } }` | 見出しカード（水色の光る極太。`\n` で2行。長いと自動で小さくなる。1行は約12字まで） |
| `{ "findings": { "items": [{ "head": "関与", "body": "4人の未成年者" }] }, "label": "…" }` | FINDINGS（確認できたこと。右端に「確認」バッジ。`badge` で文字を変える・`""` で消す。3項目まで） |
| `{ "data": { "items": [{ "label": "関与", "value": "4人" }], "photo": "<キー>", "caption": "写真の説明" }, "label": "…" }` | LOCATION DATA（項目と値。`photo` があれば左に写真。`tag` で見出しの英字を変える。3項目まで） |
| `{ "list": { "photo": "<キー>", "items": [{ "head": "教育", "body": "説明" }] }, "label": "…" }` | 番号リスト（①②③。`photo` があれば左に写真。3項目まで） |
| `{ "label": "…" }` だけ | パネルはそのままで帯の文字だけ替える |
| `{ "background": "<キー>" }` | この文から背景を替える（パネルと一緒に書いてよい） |

1つの文に書けるパネルは1つ。`photo`・`data.photo`・`list.photo` は写真でも動画でもよい（動画は連番で動く）。

## 字幕の区切り

- 自動：「、」「？」「！」で分け、2〜3字の短い区切りは次とつなげる。17字を超える区切りは真ん中に近い助詞（は・が・を・に・で・と・の・も・へ・や）の後ろで分ける
- うまく分かれない文は、台本の line に `"chunks": ["今回は", "中国・広東省掲陽市で起きた", …]` と書く（つなげると読み上げの文と同じになるように）
- 時間は区切りの読みの長さ（かな1・漢字1.8・数字1.6）で割り振る。代表コマで、字幕と声がずれていないか確かめる

## 素材の入れ方

- **ベース動画（見せる映像）**：カットごとに切り出し、ffmpeg で 1920×1080 に組み上げる（字幕などの入っていないはっきりした部分を中央に高さ730px・上16pxで置き、両脇は同じ映像をぼかして暗くする）。`<id>/assets/s-<内容>.mp4` に置き、台帳に `"composed": true`・provider・sourceName・usageType "documentary"・rightsStatus・`onScreenCredit`（右上に出る。例：「映像：SNSで拡散された映像（投稿者不明）」）を記録する。例：`laika-sputnik2` のときの手順（縦型SNS動画 1180×2082 の中央 1180×1156 を使った）
- **パネルの裏のぼかした背景**：写真カードは `background` に写真と同じキーを書く（写真をぼかして裏に敷く）。文字パネルの裏は、組み上げていない（composed でない）映像のキーを `background` に書く。**キーを場面のid（`opening`・`c1` …）にすると、連番化でその場面の長さぶん取り出す**（それ以外のキーは20秒で往復ループ）
- **実際の画像**：検索で見つけた元のページ（報道・公的機関・投稿）から保存し、台帳に sourceName（媒体名。検索エンジンは書かない）・sourceUrl・creator を記録。画面の表記を指定するときは `onScreenCredit`（`\n` で2行）
- **Pexels**：`node scripts/mt.mjs pexels candidates/pick`（「※画像はイメージです」と作者名が出る）
- **AI生成**：provider `ai-generated`（「※画像はイメージです／AI生成画像」と出る）

## 見た目の部品（コード）

`src/stage.tsx`：`StageVideo`（背景・パネル・帯・字幕・音声）、パネル（`PhotoPanel`・`Headline`・`Findings`・`DataPanel`・`ListPanel`）、`Band`。design.json に `stage` があるパターンだけが使い、pattern-02・03 の見た目は変わらない（`src/Video.tsx` が振り分け）。字幕の区切りは `src/timeline.ts` の `splitChunks`・`chunkCues`（subtitle.json の `chunk` があるときだけ）。

## 動画ごとに決めること（パターンでは決めない）

台本（ユーザー）、ベース動画のどこを使うか、写真カードの画像と出典、帯の文字、パネルの中身、サムネイルの文言と写真、BGM。
