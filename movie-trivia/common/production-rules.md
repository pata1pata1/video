# movie-trivia 共通の制作ルール

どのパターン・どのテーマの動画にも適用する。

## 事実確認

- 事実は公的データ・研究・一次情報（研究機関・政府・企業の発表、論文）で確認できるものだけ使う
- **報道と一次情報が食い違うときは一次情報に従う**。視聴者が報道で見ている可能性が高い食い違いは、台本で「一部の報道では〜ですが、発表では〜」と触れる
- 根拠のない数字・あおり（「9割が知らない」等）はタイトル・サムネイルに使わない
- 将来の予定は「目標」「計画」と分かる言い方にする
- 研究者などの発言は、出典に書かれている範囲で引用する

## 出典の記録

- `<id>/input/youtube.md` に、説明文用の「出典」一覧と「事実確認メモ」（台本の数字 → 根拠）の表を書く
- 素材のクレジット（Pexels の作者と元ページ、VOICEVOX の話者、BGM）も同じファイルの説明文に載せる。Pexels License ではクレジット不要だが記載する

## 完成時の報告

- 動画が完成したら、MP4・サムネイルに加えて **タイトル・説明文・ハッシュタグ** をそのまま貼れる形で報告に出す（`<id>/input/youtube.md` と同じ内容）
- ハッシュタグは説明文の最後に5〜8個。最初の3つがタイトルの上に出るので、人名・事件名などテーマの固有名詞を先に置く

## 素材の確認

- Pexels の候補一覧はサムネイル1枚だけなので、採用前にクリップ全体から数コマ抜き出して見る：種類違い・ぼけ・暗すぎ・人物の顔やロゴの写り込み
- 検索語どおりの物が写っているか必ず見る（例：「emperor penguin」で検索してもオウサマペンギンばかり出た）
- 映像と字幕の組み合わせで誤解を生まないか見る（例：別の施設の映像に「この装置」と重ねない）
- 出典台帳 `<id>/assets/asset-sources.json` の `rightsStatus` は `unknown` のまま。人が元ページを確認する
- ユーザー提供の素材は台帳に `provider: "user"` で入れ、出どころ・使用許諾が分かるまで説明文に【要記入】を残す

## 読み

- `--dry-run` でカナを全文確認し、誤読は台本の `pronunciation` に入れる（長い語から順に置換される）
- 置換後も前後とつながって誤読するときはカタカナで書く（例：三重水素 → サンジュウスイソ）
